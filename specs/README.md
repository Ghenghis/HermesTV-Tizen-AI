# DaveTV Spec Workflow

Use this folder for agent-readable feature specs. The process mirrors Spec Kit:

1. Specify: `specs/templates/spec.md`
2. Plan: `specs/templates/plan.md`
3. Tasks: `specs/templates/tasks.md`
4. Implement: code task-by-task with proof

Recommended naming:

```text
specs/NNN-short-feature-name/spec.md
specs/NNN-short-feature-name/plan.md
specs/NNN-short-feature-name/tasks.md
specs/NNN-short-feature-name/proof.md
```

Do not use a spec to weaken `AGENTS.md` or `.agents/constitution.md`.

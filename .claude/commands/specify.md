# /specify

Create or update a DaveTV feature spec using `specs/templates/spec.md`.

Before writing:

1. Read `AGENTS.md`.
2. Read `.agents/constitution.md`.
3. Ask only for missing business intent that cannot be inferred.

Output:

- Proposed spec path under `specs/`.
- Completed spec with user journeys, success criteria, non-goals, contracts,
  security, and proof requirements.
- No implementation yet unless the user explicitly asks to continue.

credentialGuard coverage

The credential guard middleware lives at src/middleware/credentialGuard.js and is mounted globally in src/index.js with app.use(credentialGuard) AFTER request logging and BEFORE the route routers. It wraps res.json on every request, scanning the serialized body for forbidden patterns and replacing the body with a generic 500 security error when any match:

  • /get.php?username= — Xtreme Codes M3U credential URL
  • /player_api.php — Xtreme Codes player API endpoint
  • x-ui-token — 3X-UI panel session token
  • client_secret — OAuth client secret
  • AZURE_TTS_KEY — Azure TTS env var name
  • DEEPSEEK_API_KEY — DeepSeek env var name
  • api[_\-]?key\s*[:=] — generic API key assignment
  • password\s*[:=] — generic password assignment
  • bearer\s+[A-Za-z0-9...]+ — Bearer token value

The binary audio response from /api/tts/speak does not pass through res.json — it uses res.send(Buffer) directly, so credentialGuard does not scan it. That endpoint enforces credential safety inline via the CREDENTIAL_PATTERN regex applied to the request text body before synthesis.

Mount-path drift between web and Tizen native
  • /health (no /api prefix) — Tizen getHealth() calls /api/health → 404.
  • /api/profile/:id/update — Tizen updateProfile() POSTs to a path the backend does not declare → 404.
  • /api/cmd, /api/cmd/audit — Tizen sendCommand()/getAuditLog() reference endpoints with no source file.
  • /api/quality/*, /api/jellyfin/* — Tizen native client references routes that do not exist in services/hermes-tv-api/src/routes/ at all.
Endpoints that should drop mock data when real providers wired
  • /api/actors — 5 hardcoded actors.
  • /api/channels — derived from SEED_CATALOG via LIVE_DEFS.
  • /api/catalog — seed unless Jellyfin reachable + iptv-org enabled.
  • /api/epg/:channelId — stub always returns empty programs.
  • /api/epg/grid — two hardcoded mock programs.
  • /api/providers — hardcoded health ok, slots 0/2.
  • /api/play — operates on seed items; ticket valid but /api/play/:ticket/stream returns 503.
  • /api/source-health/:provider_id/:item_id — returns not_configured until provider env vars set.
Routes vs spec-listed file names
  • Spec listed actors.js as a route file. There is no routes/actors.js — the GET /api/actors endpoint is defined inside routes/catalog.js.
  • All other 17 spec file names map 1-to-1 to files in services/hermes-tv-api/src/routes/.
